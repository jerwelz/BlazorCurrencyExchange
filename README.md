# Blazor Currency Exchange

A currency exchange dashboard built with C# and Blazor.

The application retrieves historical exchange rate data from the Frankfurter API and displays it using interactive charts.

## Features

- Historical exchange rates
- Multiple currencies
- Selectable time ranges
- Interactive charts
- Responsive interface

## Built With

- C#
- .NET / Blazor
- Frankfurter API
- Blazor-ApexCharts

## Data Source

Exchange rate data is provided by the Frankfurter API, which tracks reference exchange rates published by the European Central Bank.

## Purpose

This project was built to improve my experience with C#, Blazor, asynchronous programming, APIs and data visualisation.
